# Esat Gözütok — Pixel Portfolio

My interactive pixel-art portfolio: education, experience, skills and projects. Built with plain HTML, CSS and JavaScript.

- English by default, with a Turkish (TR) option
- Original chiptune background music generated live with the Web Audio API
- There is a secret code hidden somewhere on the page 👀

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 5173
```
